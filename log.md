## 2026-10-29 — Fix overlapping native genre-tag requests

Fixed the misleading Liked Song Filters load/save notification. Spotify's native Liked Songs page and the extension request the same genre tags; Spotify's request bridge rejects the overlap with `DUPLICATE_REQUEST_ERROR`. The extension reported that temporary conflict as a failure and delayed recovery for 30 seconds. Version 0.1.1 retries duplicates quietly with bounded backoff, ignores late results/errors from an unloaded copy or a previous navigation, and resets retry state on navigation. Genuine errors identify initialization, genre tags, reading, or saving. Saved-filter formats and keys are unchanged. Rebuilt and applied the corrected bundle to the local prepared and running installations.

- **Files:** `extensions/liked-song-filters/src/{lifecycle,storage}.js`, `extensions/liked-song-filters/dist/liked-song-filters.js`, `extensions/liked-song-filters/package.json`, `extensions/liked-song-filters/README.md`, `extensions/liked-song-filters/tests/{lifecycle,storage}.test.cjs`, `extensions/liked-song-filters/tests/live-{lifecycle,smoke}.js`.
- **Verification:** Live reproduction with only the manually installed script loaded: native request succeeded in 213 ms, overlapping request failed immediately, Add Tag stayed absent until the old 30-second retry; no matching Marketplace-installed cache entries. `node --test --test-name-pattern='native tag request overlap|unloaded extension|leaving Liked Songs|genuine tag failures|persistent duplicate' extensions/liked-song-filters/tests/lifecycle.test.cjs` — five regressions failed before the fix. `npm run build` and `npm test` — 26 tests passed and Marketplace artifacts validated after the fix. `playwright-cli -s=spotify-maintenance --raw run-code --filename=extensions/liked-song-filters/tests/live-lifecycle.js` (using the absolute script path from the retained session's working directory) — exercised three real native overlaps without warnings, mounted one Add Tag button each time in 944/504/510 ms, and preserved playback and original page.
